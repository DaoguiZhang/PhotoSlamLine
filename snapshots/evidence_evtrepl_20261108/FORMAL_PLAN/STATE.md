# 正式对比状态

**计划定义（本轮范围修正后）**：`O_core` × 30 格 × 5 次 = 150 项；
`L_core`（结构线损失关闭，V=0 N=0）× 30 格 × 5 次 = 150 项；**合计 300 项**。
`L_core-Full`（结构损失 ON）**不是**正式必跑方法。

| 项 | 值 |
|---|---|
| 状态 | **NOT_STARTED**（450 项旧计划从未启动；未核销任何 L_Full 项） |
| 已产生的运行 | 仅本轮必要短跑：结构损失 OFF/ON 对照 4 次 × 200 步（`../lossaudit/`）、退出回归 4 例（`../exitreg/`） |
| 原因 1 | `O_core` 与 `L_core` 的共同条件需人拍板（`README.md` §3.1：`off_cfg` 不清线采样种子，且不新增 L 点-only 分支） |
| 原因 2 | 墙钟：300 次整系统运行 ≈ 25 h 串行独占；另需 ≥ 数十 GB 空闲（当前仅 ~22 GB） |
| 已关闭的旧原因 | 门禁 5 / N 是否入版：N 已定 0，不再阻塞；"是否跑 L_Full"：已定为不跑 |
| 已具备 | 30 格定义与预算逐键核对；30/30 数据集与配置存在；调度器（单实例/可恢复/串行/不重试/PID/进度/不覆盖）就绪；L_core 配置 = 封存 `off_cfg`（三键 0.0，与 `../cfg_v2/` 一致）且已通过损失审计 |
| 未具备 | `O_core` 的 30 格 argv 生成器 `make_argv.py`（故意未建）；≥25 h 时间窗；产物存放位置 |
| 禁止 | 启动第二个 GPU 调度器；修改在飞行中的二进制/配置/清单；用同龄门槛凑更新数量 |
| 若要启动 | 先定 README §5 的两件事，再补 `make_argv.py`，然后 `./schedule_formal.sh <A_bin> <A_tag> <B_bin> <B_tag> 5` |
